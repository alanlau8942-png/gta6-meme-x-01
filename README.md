An AI-made GTA 6 launch-week meme: 13 years waiting, 1 sick day, 0 regrets — a Vice City sunset, Jason and Lucia's convertible, and make.fun's ghost riding along in the back seat. Posted on X for make.fun's "Post a GTA 6 meme on X" bounty ($500 in USDC over 50 places). The post itself is the entry: an AI judge compares the posts two at a time on make.fun in the picture, how funny and GTA-6-specific the joke is, how well it sells make.fun, and how short, original and clean it is.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `POST.json` from the repository root to `/output/POST.json` — that is all it has to do. `POST.json` names the X post; the house reads the post itself from X.
